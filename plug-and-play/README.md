# Plug-and-play

Componentes reutilizables para copiar a otros proyectos sin arrastrar dependencias propias de esta plataforma.

## Kits disponibles

- `daily-video-kit`: paquete Daily completo para otros proyectos: videollamada embebida, transcripcion, configuracion reusable, guardado incremental, aviso de abandono y helpers de bolsa de minutos.

## Criterios

- No incluir credenciales reales.
- Mantener el codigo desacoplado de modelos, controladores y rutas de Ambipar.
- Incluir siempre un `README.md` con instalacion, uso y puntos de adaptacion.
- Agregar ejemplos completos, pero pequenos.
- Mantener cada kit en su propia carpeta para poder copiarlo o comprimirlo completo.
